# FileBrowserR v0.2.56

## 変更内容

- ディスク使用量のマップと「内訳・操作」の選択をそろえました。右クリックした行に対して場所を開いたり、削除の確認画面を表示したりできます。
- メニューを開いた後にスキャン結果が変わると、古い結果への操作を中止します。
- 音量ミキサーで固定したアプリが停止しても、表示名を使って検索できます。名前は同じ画面を使っている間保持します。
- 使い方の文字コード設定、長い行の省略表示、SHA-256の名称を現在の画面に合わせました。ポータブル版の更新は、設定をコピーして起動方法を用意する順で説明しています。

## ダウンロードと起動

Windows 11 x64 向けです。初めて使う場合は [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールしてください。ZIPを新しいフォルダーに展開し、`FileBrowserR.exe` を開くと起動します。

ポータブル版を更新する場合は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
