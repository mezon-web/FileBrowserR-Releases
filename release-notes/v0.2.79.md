# FileBrowserR v0.2.79

- ファイル一覧の先頭に「..」を表示し、ダブルクリックまたは選択してEnterで親フォルダーへ戻れます。中クリックと右クリックの「新しいタブで開く」にも対応しました。
- 書庫内の階層・書庫からの退出・UNC共有に対応します。「..」は並べ替え、絞り込み、ファイルの選択・操作に混ざりません。
- 専用設定画面を「表示」「ファイル一覧」に分け、「..」の表示をON/OFFできます。初期状態はONです。

配布ZIPを新規展開したEXEを隔離Win32デスクトップで起動し、初期ON、専用設定画面でのOFF・ON、「..」から親フォルダーへの移動を確認しました。入力デスクトップは切り替えず、テストプロセスを終了しました。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して FileBrowserR.exe を起動してください。ポータブル設定を引き継ぐ場合は、新しいフォルダーにUserDataをコピーし、--portableで起動してください。
