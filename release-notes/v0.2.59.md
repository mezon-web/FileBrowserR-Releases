# FileBrowserR v0.2.59

ディスク使用量で、図の上に「表示中」のフォルダー名とパスを強調表示します。スキャン対象の入力欄と区別でき、今どこの図を開いているか確認しやすくなりました。

- サンバースト・ツリーマップ・アイシクルで領域を選ぶと、下の内訳が連動します。フォルダーは直下、ファイルは親の内訳、小項目はその集団、システム・未分類は読み取り専用の容量情報を表示します。
- 内訳を閉じたまま選択を変えられ、小項目の集団は表示形式・段数・容量基準を変えても保ちます。
- システムモニターは上部の「表示 ▾」から設定を開きます。温度の診断・再検出・管理者での温度取得は同じメニューの下側へまとめました。
- ファイル一覧の上部に「一覧を読み込んでいます…」の帯を出さず、下部の状態欄に進捗と取消ボタンを表示します。読み込みの開始・完了でも一覧の高さが変わらないようにしました。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
