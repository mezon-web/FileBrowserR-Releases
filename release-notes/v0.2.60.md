# FileBrowserR v0.2.60

ツリーのフォルダー名を1回クリックすると一覧に開きます。2分割では最後に操作したファイルペインへ移動します。左の矢印でツリーを展開・折りたたみ、中クリックで新しいタブに開けます。

- 続けてフォルダーを開いたりツリーを展開したりする操作を速くしました。
- 通常フォルダー間の移動中は、移動先の項目が届くまで直前の一覧を薄く表示します。その間、前の項目は選択・操作できません。時間のかかる読み取りは下部の状態欄で確認・取消できます。
- ファイル一覧の左上から「左」「右」「操作対象」の文字を外し、タブを左に詰めました。操作中のペインは枠色で確認できます。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
