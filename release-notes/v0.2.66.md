# FileBrowserR v0.2.66

- ランチャーの「開く対象」の「参照 ▾」からファイルとフォルダーを選べます。一括登録では名前・種類・場所・選択件数を表示し、「すべて選択」「選択解除」を追加しました。
- ツリーで選んだ場所をEnterで開けます。書庫には専用アイコンと閲覧専用の説明を表示します。
- F1の使い方画面に、Ctrl+F、Enter／F3、Shift+F3で操作できる文字列検索を追加しました。
- ディスクの長いパスを読み上げでも全文で確認できるようにし、ツリーマップの操作ヒントを実際の操作に合わせました。
- メモリ内訳の空一覧で、更新のたびに並べ替え条件が増える問題を修正しました。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
