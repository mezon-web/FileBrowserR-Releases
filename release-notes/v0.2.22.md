# FileBrowserR v0.2.22

マウスのサイドボタンで戻る／進むを使えるようにし、比較本文の上部へ「↑」を追加しました。

- サイドボタン1（XButton1）で戻る、サイドボタン2（XButton2）で進みます。通常のファイル一覧は、キーボードフォーカスに関係なくマウスがあるペインの履歴を操作します。
- 比較では、フォルダー・表示形式・開いた本文の履歴を戻る／進むことができます。Alt+←／Alt+→も同じ動作です。再比較・対象変更・比較終了では履歴を消去します。
- ディスク使用量の階層移動にも対応し、内蔵ペインと別ウィンドウの両方で使えます。ほかのファイルペインへ操作は渡しません。
- 本文の上部に、フォルダー表示と同じ線画の「↑」を配置。選択・スクロール位置を保って、ファイルを開いた元の比較一覧へ戻れます。Alt+↑でも操作できます。ファイル同士の直接比較は戻る比較一覧がないため、このボタンは無効です。

通常一覧の左右独立した移動、履歴の端・新しい移動後の進む履歴の破棄、比較のフォルダー／本文の往復、隠れた一覧への誤操作防止、ディスク使用量の内蔵／別窓での移動を検査しました。既存の比較内容・SHA-256・文字コード・取消・表示切替・復帰と、中クリックのタブ追加／終了なども確認しています。
