# FileBrowserR v0.2.81

- ランチャーを開き直すと登録項目は未選択になり、検索・グループ・スクロール位置は引き継ぎます。
- 空き領域の右クリックで登録や配置の取り消しができます。項目を右クリックすると、その項目を開く、編集する、アイコンを変更する、グループを移す、登録を削除する操作が使えます。
- アイコン表示・一覧表示とも、ドラッグ中に周囲の項目が動いて挿入位置を示します。上下端での自動スクロールと、グループ見出しへのドロップにも対応しました。
- メニューバーの「ヘルプ」の右に「設定」を追加しました。左右のフォルダーを直接比較するコマンドは「左右を比較」に統一しました。

## ダウンロードと起動

Windows 11 x64向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。ポータブル設定を引き継ぐ場合は、新しいフォルダーに `UserData` をコピーし、`--portable` で起動してください。
