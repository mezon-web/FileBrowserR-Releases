# FileBrowserR v0.2.55

## v0.2.53 からの変更

- 右端の機能アイコンを並べ替えるとき、最後のアイコンより下の余白で離すと末尾に移動します。並べた順番は次回の起動でも使えます。
- メモリマップから絞り込み欄を外しました。以前に検索語を入力していても、マップと「内訳」のアプリ一覧には計測した全アプリが表示されます。
- 音量ミキサーではミュートボタンを少し右に寄せ、幅の狭いペインでもアプリアイコンと見分けやすくしました。
- 配布フォルダーを `FileBrowserR.exe`、`使い方.md`、ライセンス通知の `licenses` に整理しました。アプリの依存DLLはEXEに同梱しています。

## ダウンロードと起動

Windows 11 x64 向けです。初めて使う場合は [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールしてください。ZIPを新しいフォルダーに展開し、`FileBrowserR.exe` を開くと起動します。
