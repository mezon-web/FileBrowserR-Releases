# FileBrowserR v0.2.80

- 空フォルダー間の移動、左右ペインの連動移動、読み込みの取消や失敗時に、一覧先頭の「..」が古い移動先を示す問題を修正しました。表示を切り替えてもファイルの選択とスクロール位置を保持します。
- 複数ウィンドウの保存が重なったとき、「..」やツールバー項目の最後の表示操作を保持します。表示設定の変更で一覧を読み直す処理も減らしました。
- ツリーを更新しても、画面内にあった選択行が残る場合は、更新後も表示範囲に収まるようにしました。
- 移動・改名の取り消しでは、元の親フォルダーと対象の識別情報・更新状態を照合します。フォルダー配下の差し替えも確認し、大量の取り消し後の結果整理を高速化しました。
- 書庫の展開と7-Zipメニューの回帰テストで、展開するファイルを明示的に選ぶようにしました。

新規展開した配布EXEを隔離Win32デスクトップで起動し、「..」での親フォルダー移動、設定画面でのON/OFF、PDFアイコンがWindows Shellの表示と一致することを確認しました。

## ダウンロードと起動

Windows 11 x64向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーへ展開して FileBrowserR.exe を起動してください。ポータブル設定を引き継ぐ場合は、新しいフォルダーへ UserData をコピーし、--portable で起動してください。
