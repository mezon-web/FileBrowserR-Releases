# FileBrowserR v0.2.72

- ランチャーの表記を、ファイル・フォルダー・URLを扱う現在の機能に合わせました。フォルダーの設定は「フォルダーの場合」と明示します。
- 「圧縮・展開」の位置を固定し、7-Zipの読み込みや内蔵機能への切り替えで、右クリックメニューのほかの項目が動かないようにしました。
- ディスクの削除項目を実行できる状態に合わせて無効化します。未完了の結果では「削除を実行するには再スキャンしてください。」と表示し、理由を読み上げでも確認できます。
- ガイド検索は、検索欄へ入力中も現在の一致箇所を強調します。空欄や一致なしでは前の強調を消します。
- 取消後に遅れて届いた進捗で「実行中」に戻らず、終了まで「取消し中…」を表示します。
- ディスク使用量のチェックボックスを「管理者(高速)」に変更しました。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
