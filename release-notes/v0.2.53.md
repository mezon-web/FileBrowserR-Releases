# FileBrowserR v0.2.53

音量ミキサーの「アプリ別」で、名前の左にアプリアイコンが表示されます。SoundMixerR v0.2.18の修正を取り込み、Teamsなどの登録アプリはWindowsの登録名とアイコン、通常のアプリはローカルEXEのアイコンで見分けられるようになりました。音量やミュートの操作中に既定のスピーカー・マイクが変わると、その操作を中断します。

## 前回の公開版 v0.2.49 からの変更

- **左ツリー**　ホーム・ドライブ・ネットワーク・フォルダーにアイコンを追加しました。行間を詰め、選択色をファイル一覧とそろえました。
- **ファイル一覧**　内容が変わっていないフォルダーの再読み込みで行データを再利用し、拡張子順の並べ替えに必要な一時メモリを削減しました。
- **機能ペイン**　ランチャーの検索と音量表示の更新を軽くしました。ディスクの内訳は折りたたむと行データを解放し、システムモニターは非表示が1分続くと通常の計測ワーカーを終了します。再表示すると計測を再開します。

## ダウンロードと起動

[Windows x64用ZIP](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.53/FileBrowserR-v0.2.53-win-x64.zip)を新しいフォルダーに展開し、`FileBrowserR.exe`を起動してください。動作には[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。

Windowsの隔離デスクトップでGUI検査85件、単独EXEの配布検査20件が合格しました。Teams、Microsoft 365 Copilot、電卓は実際のWindows登録からアイコンを取得して表示を確認しました。機器切り替えはテスト用データで検証しました。
