# FileBrowserR v0.2.16

フォルダーとテキストを左右に並べる、読み取り専用の「比較」を追加しました。比較を終了すると元のファイルタブ・選択・分割状態へ戻ります。

## ダウンロードと起動

- [FileBrowserR-v0.2.16-win-x64.zip](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.16/FileBrowserR-v0.2.16-win-x64.zip)
- [SHA-256](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.16/FileBrowserR-v0.2.16-win-x64.sha256)
- [使い方](https://github.com/mezon-web/FileBrowserR-Releases/blob/main/使い方.md)

Windows 11 x64用です。新しいフォルダーへZIPを展開し、`FileBrowserR.exe`を起動してください。ランタイム・関連DLL・日本語リソースはEXEへ内包しており、追加インストールは不要です。

## 使い方と変更内容

1. 右端の「比較」アイコン、機能メニュー、コマンド検索から開きます。
2. 左右のパスを指定し、「開始」を押します。「参照」やパス欄へのファイル・フォルダーのドロップも使えます。
3. フォルダー結果では相対パスを対応付け、片側だけの項目は反対側を空欄にします。フォルダーは展開、ファイルは本文比較へ進めます。

- 既定はサブフォルダーを含む内容比較で、一致項目も表示します。「違い・未確認の項目だけ」で絞り込めます。内容・SHA-256とも同サイズ・同日時でも読み取りを省略しません。SHA-256は全内容を読むため高速化を保証しません。
- 一致・内容相違・左のみ・右のみ・種類相違・確認不可・未比較を区別します。リンク先をたどらず、読み取り途中の変更や失敗を一致扱いにしません。
- 本文は行番号・追加／削除／変更行・文字単位の差分を表示し、縦スクロールを同期します。F7／Shift+F7で差分へ移動できます。BOM付きUTF-8／UTF-16／UTF-32とBOMなしUTF-8、左右個別のCP932指定に対応し、BOM・改行・文字コードの違いも説明します。
- 本文表示は片側10 MiB・10万行まで。長い行では文字単位の強調を省略し、1行16,384文字を超える表示は省略を明示します。行全体の判定は維持します。バイナリや本文上限超過でも内容／ハッシュの比較は可能です。
- F5で再比較、Escで実行中の処理を中止します。処理は終了可能なワーカーへ分離し、30秒間進捗がなければ中断します。再比較中も既存の行を保持します。
- 「比較終了」、ペインの×、Ctrl+W、他機能への切替で通常表示へ戻ります。対象と条件だけを保存し、結果・本文・ハッシュは保存せず、起動時に比較を自動実行しません。

編集・コピー・マージ、画像・PDF・Office文書の専用比較、書庫内部・属性・アクセス権・代替データストリームの比較は含みません。

## 検証範囲

ローカルReleaseビルドは警告0・エラー0。比較専用13判定、コア・ファイル操作43判定、既存UI77判定、機能アイコン等6判定に合格しました。重複する判定は合算していません。両テーマ、幅1,000／1,250 DIP、文字13／20 DIP、同期スクロール、差分移動、取消・遅延結果の破棄を隔離Windowsデスクトップで確認しています。

最終ZIPの内容・ハッシュ・個人情報混入を検査し、EXEだけを別フォルダーへコピーした起動・ワーカー13判定にも合格しました。日本語リソース12個とDiffPlexを含む257項目をEXEへ格納し、DiffPlex 1.9.0のApache-2.0ライセンス通知を同梱しています。
