# FileBrowserR v0.2.20

比較のフォルダー移動と、ファイル／フォルダーの対応付けを見直し、テーマ表示を確認・修正しました。

- 「フォルダー形式」は現在の階層の直下だけを表示。ダブルクリック／Enterで左右同時に中へ進み、「↑」・パンくず・Alt+↑で親へ戻ります。階層ごとの選択・スクロールを保持し、「ファイルのみ」は全階層を表示します。
- 同名でもファイルとフォルダーは別項目です。「左のみ」のファイルと「右のみ」のフォルダーなど、別々の行として表示し、それぞれ本文やフォルダーを開けます。
- 比較中のお気に入り・履歴などがダークテーマでも白くなる表示を修正。共通の一覧・入力欄は操作不可でもテーマの背景を保ちます。メイン画面・機能・ダイアログの配色も確認しました。
