# FileBrowserR v0.2.82

- ランチャー、ディスク使用量、音量ミキサー、比較を開いたり切り替えたりしたときに、検索欄やパス欄へ自動でフォーカスを当てないようにしました。入力するときは欄をクリックするか、Tabで移動できます。
- ディスク使用量の「参照…」でフォルダーを選択した後も、スキャン先の入力欄に自動でフォーカスを当てません。

## ダウンロードと起動

Windows 11 x64向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。
