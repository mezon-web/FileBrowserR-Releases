# FileBrowserR v0.2.49

- **EXEアイコン**　ファイル一覧と左右の比較一覧に、各EXEのアイコンを表示します。左右に同名のEXEがあっても、それぞれの実ファイルから読み取ります。取得中・取得失敗時と書庫内のEXEには汎用アイコンを表示します。
- **メモリマップ**　マップでアプリを選ぶと、下部にアプリ名・専用RAM・約10秒前からの増減・プロセス数がまとまります。「内訳」でアプリ一覧とプロセス一覧を切り替えられます。プロセス一覧で選んだPIDがすべて終了すると、その選択に対する操作は無効になります。
- **システムモニター**　「表示・更新…」で、左端のつまみをドラッグすると挿入位置に線が出ます。項目名を左クリックして「上へ」「下へ」で動かすこともできます。表示チェックと並び順は「OK」で保存します。

## ダウンロードと起動

[Windows x64用ZIP](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.49/FileBrowserR-v0.2.49-win-x64.zip)を新しいフォルダーに展開し、`FileBrowserR.exe`を起動してください。動作には[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。
