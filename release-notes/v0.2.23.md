# FileBrowserR v0.2.23

比較画面の上部をコンパクトにし、操作部分と一覧の境界を分かりやすくしました。

- 左右の対象パスに「左」「右」を表示し、それぞれの参照ボタンを入力欄と同じ枠へまとめました。入力欄・ボタン・パンくずの上下余白を縮小しています。
- 階層ナビと本文見出しに薄い背景色を付け、下端の細い線から比較結果が始まる構成にしました。画面全体の外枠と左右の境界もテーマに合わせています。
- 本文表示も同じ配置に揃え、見出しの幅は一覧の幅に追従します。新しい操作行は追加していません。「↑」やサイドボタン、選択・スクロール位置の保持は引き続き使えます。
- 実際のファイル名に環境変数風の文字列がある場合、内部のファイル操作で再展開して別の項目を扱う問題を修正しました。変数から始まるユーザー入力の展開は維持します。
- フォルダーツリーの読み込みに失敗・取消した後も展開操作から再試行できるようにしました。途中まで取得した子項目を正常完了として表示しません。

## 検証

ローカルReleaseビルドは警告0・エラー0。比較25判定、パス安全性・ツリー再試行7判定、配布EXE単体の起動・CLI・ワーカー15判定に合格しました。

比較はフォルダー形式・入れ子・ファイルのみ・本文、ライト／ダーク、文字13／20 DIP、通常幅と900 DIPの狭いウィンドウを既存の描画検査で確認し、代表画像を目視しました。本文の「↑」、選択・スクロールの復帰、サイドボタン、対象パスへのFileDrop、表示切替、比較終了時の復帰も回帰検査しています。

パスとツリーは専用データで実際のWindows Shellによる削除・コピー・移動・改名と取り消し、検索、ZIP作成・展開、失敗後の再試行を確認しました。途中失敗・取消は検証用ワーカーも使っています。

検査は隔離Win32デスクトップのWPFイベント・UI Automation・描画です。通常デスクトップの入力・クリップボードには触れていません。実マウスの物理入力、実モニターDPI切替、実NAS・実UAC・長時間運用は今回未確認です。全体回帰と一覧性能は今回再測定しておらず、過去の結果とは分けて同梱の検証結果.mdに記載しています。
