# FileBrowserR v0.2.62

ディスクマップの直上に「場所」と「スキャン対象」を2行で表示します。「場所」は今開いている階層、「スキャン対象」はその図を作ったスキャンの起点です。

- 長いパスは末尾のフォルダー名を残して省略します。パスにマウスを重ねるとフルパスを確認できます。
- 上部の「スキャン先の指定」で次の場所を入力できます。新しいマップに切り替わると、2行のパスも一緒に更新されます。
- 内訳は初めは閉じてあり、開くと名前と容量の2列で表示します。容量は単位付きで右にそろえ、長い名前はツールチップでも読めます。別の階層への移動や再スキャン、別ウィンドウとの往復でも開閉状態を保ちます。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
