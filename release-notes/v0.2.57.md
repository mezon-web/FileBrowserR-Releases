# FileBrowserR v0.2.57

## 変更内容

- 左ツリーを一覧の名前昇順と同じ自然順にしました。「フォルダー2」は「フォルダー10」より前になります。
- ディスク使用量の「戻る」「進む」「親フォルダーへ」を、移動できる場合だけ押せるようにしました。
- F1の簡易ヘルプに「詳しい使い方」を追加しました。同梱ガイドをオフラインで開き、テキストを選択してコピーできます。
- メモリマップの「内訳」で、列見出しをクリックしてアプリ名・PID・専用RAM・コミットを昇順／降順に並べ替えられます。計測が更新されても、選んだ並び順と対象の選択、読んでいる位置を保ちます。並び順は同じ画面内で保持します。
- 音声アプリの名前の下に、必要なときだけ「待機中」「一部ミュート」を表示します。

## ダウンロードと起動

Windows 11 x64 向けです。初めて使う場合は [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールしてください。ZIPを新しいフォルダーに展開し、`FileBrowserR.exe` を開くと起動します。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
