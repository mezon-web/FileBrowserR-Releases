# FileBrowserR v0.2.61

ZIP・7z・RARが左のファイルツリーに並びます。書庫を1回クリックすると操作中のペインに中身が表示され、矢印で内部フォルダーを展開できます。

- ツリーから内部フォルダーを開けます。一覧から階層を移動した場合やタブを切り替えた場合も、ツリーがその場所を選択します。2分割では最後に操作したペインに追従します。
- 空フォルダー、通常ファイルだけのフォルダー、内部フォルダーがない書庫には、最初から展開矢印を出しません。中身を取得できない場所は矢印から再試行できます。
- システムモニターの計測項目の間の横線を外しました。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
