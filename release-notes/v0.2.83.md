# FileBrowserR v0.2.83

- 左右2分割で操作中のファイルペインは、タブ帯の青い上線と淡い青の背景で見分けられます。クリックやF6で操作先を切り替えると目印も移ります。
- お気に入りの行にマウスを重ねるか選択すると、右端に「×」が表示されます。クリックでその行の登録を削除でき、右クリックメニューの「お気に入りの変更を元に戻す」で復元できます。
- お気に入りの右クリックメニューでは「登録を削除」を一番下に移し、「お気に入りを検索」を外しました。上部の検索欄やCtrl+F／Ctrl+Kで絞り込めます。

## ダウンロードと起動

Windows 11 x64向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。
