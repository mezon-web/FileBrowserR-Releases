# FileBrowserR v0.2.70

- 通常のファイル一覧で、右クリックからインストール済み7-Zipの圧縮・展開メニューを使えます。項目は7-Zipの設定を反映し、アプリの配色・文字サイズで表示します。
- 「圧縮…」「展開…」は7-Zip側で保存先などを指定します。「ここに展開」などの即時操作も使えます。
- 7-Zipを利用できない場合や取得の失敗・時間切れでは、内蔵の項目に切り替えます。書庫内の選択展開は、引き続き内蔵の保存先指定画面を使います。
- 開くだけでは処理を始めず、閉じたメニューや変更前の選択は実行しません。開始済みの7-Zip処理はFileBrowserRを終了しても継続します。

7-Zip本体は同梱していません。7-Zipのメニューには、Windowsに登録済みのx64シェル拡張が必要です。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
