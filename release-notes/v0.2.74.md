# FileBrowserR v0.2.74

- ツリーの右クリックに「開く」「新しいタブで開く」「ディスク使用量を表示」「パスをコピー」「Explorerで表示」「プロパティ」「更新」を追加しました。右クリックだけでは一覧の場所を変えません。
- 一覧とツリーの「ディスク使用量を表示」で、対象フォルダーのスキャンをすぐ開始します。一覧では、選択フォルダー、ファイルの親フォルダー、未選択時の現在地が対象です。
- 実行中のスキャンは別の対象で上書きせず、完了または中止後に指定するよう案内します。右の機能アイコンによる開閉も維持します。

## ダウンロードと起動

Windows 11 x64 向けです。[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0) をインストールし、ZIPを新しいフォルダーに展開して `FileBrowserR.exe` を起動してください。

ポータブル版の更新時は、旧版を終了してから新しいZIPを展開し、`UserData` をコピーしてください。起動前に `portable.flag` を用意するか、新しいEXEに `--portable` を指定します。
