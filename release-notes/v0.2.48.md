# FileBrowserR v0.2.48

ディスク使用量の操作と、マップの文字の読みやすさを改善しました。前回の公開版v0.2.23以降の比較・ツリー・機能バーの更新も含みます。

## 今回の改善

- ディスク使用量の操作を「スキャン → 中止 → 管理者」の順へそろえ、スキャンを青系の背景・枠と少し太い文字で強調しました。狭いペインでは操作を折り返します。
- サンバースト・アイシクル・ツリーマップの色付き領域を、濃い背景と白い文字へ統一しました。深い階層でも文字と背景の明暗差を保ち、中央の説明はテーマに追従します。
- 右端の同じ機能アイコンを押すと収納し、再度押すと状態を保って表示します。比較以外の5機能で、押下・解放からこの動作を確認しました。比較の終了時は結果を破棄し、分離ウィンドウは前面に出します。

## 前回の公開版からの主な更新

- 比較画面を全幅にし、条件は「比較設定…」へ整理。フォルダー比較の左右2ペイン／統合、ツリー／ファイルのみ、種類別の絞り込み、独立したカスタム列を使えます。
- 書庫内比較を有効にすると、書庫をフォルダーのように展開し、内部パス・種類・左右サイズ・比較結果を閲覧できます。初期設定はOFFです。
- 条件変更後は「再比較待ち」と明示し、比較中の中止・部分結果・失敗時の集計を改善しました。比較詳細は一覧下の折りたたみへ移しています。
- 左端の縦バーからツリー・お気に入り・履歴を開閉できます。ツリーは一覧の現在地へ自動追従し、左右2分割では操作対象のペインに追従します。
- 音声レベル表示の位置を調整し、システムモニターは最新の数値を表示しながらバーだけを滑らかに動かします。
- 比較一覧の並べ替え・集計・表示切替で、重複処理と一時メモリの割り当てを減らしました。

## 検証

ローカルReleaseビルドは警告0・エラー0。画面・機能バー・描画更新などの関連39判定と、単独EXEの起動・CLI・ワーカー・インストール済みランタイムの使用を含む配布18判定が合格しました。GitHub Actionsは使っていません。

マップは3種類×明暗で描画と文字色を確認し、色付き領域と白文字のコントラストを検査しました。中央の説明のテーマ追従も維持しています。スキャンの操作は幅220／440 DIP・文字13／20、明暗で確認しました。

GUI検査は隔離Win32デスクトップ内で実施し、通常デスクトップの入力とクリップボードには触れていません。押下・解放の検査では隔離スレッドの入力状態を一時的に設定・復元しています。物理入力、実UAC、実NAS、実DPI切替、長時間運用は今回未確認です。比較エンジン全体・1万件性能は今回再実行しておらず、過去の検査と分けて同梱の検証結果に記載しています。
