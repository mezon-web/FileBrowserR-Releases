# FileBrowserR

Windows 11 x64向けの日本語ファイラーです。タブ付きの詳細一覧と左右2分割に、フォルダー・テキスト比較、ランチャー・ディスク使用量・メモリマップ・音量ミキサー・システムモニターをまとめています。

## ダウンロード

現在の公開版は **v0.2.22 / Windows 11 x64** です。

- **[最新版をダウンロード（v0.2.22・ランタイム同梱ZIP）](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.22/FileBrowserR-v0.2.22-win-x64.zip)**
- [ZIPのSHA-256](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.22/FileBrowserR-v0.2.22-win-x64.sha256)
- [更新内容](https://github.com/mezon-web/FileBrowserR-Releases/releases/tag/v0.2.22) · [過去バージョン](https://github.com/mezon-web/FileBrowserR-Releases/releases)
- [詳しい使い方](使い方.md)

関連DLL・日本語リソース・.NET 10 / Windows Desktop Runtimeは`FileBrowserR.exe`に内包しています。配布フォルダーに`ja`やDLL類は置かず、実行環境の追加インストールも不要です。表示は日本語のみです。

## 起動方法

1. ZIPをダウンロードし、書き込み可能なフォルダーへ全体を展開します。
2. `FileBrowserR-v0.2.22-win-x64` フォルダー内の `FileBrowserR.exe` を起動します。
3. フォルダーは左のツリーやアドレスバーから開けます。1画面の右上「＋」で左右2分割へ切り替えられます。

実行に必要なファイルはEXEへまとめています。使い方と依存ライセンスは文書として添付しています。起動時に必要なネイティブライブラリは通常`%TEMP%\.net`へ自動展開し、以後再利用します。

通常のファイル操作や機能表示は一般ユーザー権限で動作します。管理者権限を使う容量スキャンや温度取得は、機能内で明示的に選んだときだけ専用ワーカーを起動します。ドライバーを自動で導入する機能はありません。

Windowsの既定ファイラーやファイルの関連付けは変更しません。

v0.2.21では `FileBrowserR.exe --compare "左のパス" "右のパス"` で比較画面を直接開いて開始できます。`--differences-only` を添えると違い・未確認の項目だけを表示します。相対パスはコマンドを実行したフォルダーが基準です。

v0.2.22ではマウスのサイドボタンで戻る／進むに対応しました。通常一覧はマウスがあるペインの履歴を操作し、比較のフォルダー・本文とディスク使用量でも使えます。本文上部には、元の比較一覧へ戻る「↑」を追加しました。

## 主な機能

- コンパクトな詳細一覧、タブ、タブのドラッグ移動、左右2分割、作業状態の保存。
- ドライブ・フォルダーツリー、お気に入り、履歴、パンくず、UNCパスとネットワークドライブ。
- 一覧の絞り込み、正規表現、複数フォルダーの再帰検索。
- コピー・移動・削除・改名、操作キュー、一括リネーム、ZIP作成・展開、7z/RARの一覧・展開。
- ファイルとフォルダーを、お気に入りへドラッグ登録。
- フォルダーの内容／SHA-256比較、テキストの左右差分表示。読み取り専用で、階層・スクロール・差分移動に対応。
- アプリとURLを登録できるランチャー。グループ・検索・アイコン変更にも対応。
- ディスク使用量、メモリマップ、音量ミキサー、システムモニターを右側の機能ペインで切り替え。ディスク・メモリは別ウィンドウでも表示。
- ライト／ダーク／OS追従、文字サイズ、表示列、ツールバー項目の調整。

右端の機能アイコンは上下へドラッグして並べ替えできます。隣のアイコンがアニメーションで場所を空け、並び順は次回起動時にも復元します。

v0.2.20では比較をフォルダー単位で移動できるようにしました。同名のファイルとフォルダーは左右それぞれだけの別行に分け、ダークテーマで操作不可の一覧や入力欄が白くなる問題も修正しました。

1画面時はファイルペイン右上の「＋」で2画面に戻せます。左サイドバーは見出しの「×」で閉じ、上部の「›」またはCtrl+Bで再表示できます。比較結果にも通常一覧と同じ種類別アイコンを表示し、行高を共通の密度・文字サイズ設定へ揃えています。

比較結果は右ペインの「結果表示」で「フォルダー形式」「ファイルのみ」を切り替えられます。フォルダー形式は現在の階層の直下だけを表示し、ダブルクリック／Enterで中へ進み、「↑」・パンくず・Alt+↑で親へ戻ります。ファイルのみは全階層のファイルを相対パス順で表示します。移動・切り替えに再比較は不要で、階層ごとの選択・スクロールを保持します。

比較は右端の「比較」から開き、左右の対象を指定して「開始」を押します。中央が比較表示へ切り替わり、終了すると元のファイル画面へ戻ります。別の機能へ切り替えると比較結果を破棄し、対象と条件だけを保存します。編集・コピー・マージは含みません。

その他の機能は各1画面を再利用し、非表示にしても状態を保持します。継続計測は表示中だけ動き、開始済みのディスク走査は非表示でも継続します。ファイルのテキストプレビューは設けていません。

## 選択とドラッグ

ファイル名の右側にある未選択の空白からドラッグすると囲み選択できます。選択が終わった後は、色付き範囲のどこからでも選択ファイルをつかめます。選択色の長方形は最後の表示列の右端までで、その右側の空白は囲み選択に使えます。

通常の削除はごみ箱を使います。完全削除などの操作では対象を確認してください。アプリ内の「元に戻す」は、同一セッション内の上書きなし移動・改名が対象です。

## 設定と更新

通常の設定保存先は `%LocalAppData%\FileBrowserR` です。実行ファイル隣に空の `portable.flag` を置くか、`--portable` を指定した場合は隣の `UserData` を使います。

更新時はアプリを終了してから、新しいZIPを別のフォルダーへ展開してください。設定や履歴には個人のパスが含まれるため、他の人へ配布するZIPへ混ぜないでください。

## ファイルの確認

ZIPとSHA-256ファイルを保存し、PowerShellで次を実行して値を照合できます。

```powershell
Get-FileHash .\FileBrowserR-v0.2.22-win-x64.zip -Algorithm SHA256
Get-Content .\FileBrowserR-v0.2.22-win-x64.sha256
```

GitHubが自動表示する **Source code (zip / tar.gz)** は、この配布案内リポジトリの文書です。アプリ本体は上の名前付きZIPをダウンロードしてください。このリポジトリは配布物と案内用で、アプリのソースコードは含みません。
