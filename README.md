# FileBrowserR

Windows 11 x64向けの日本語ファイラーです。タブ付きのファイル一覧と左右2分割、フォルダー・テキスト比較、ランチャー、ディスク使用量、メモリマップ、音量ミキサー、システムモニターをまとめています。

## ダウンロード

現在の公開版は **v0.2.56 / Windows 11 x64** です。

- **[最新版をダウンロード（ランタイム非同梱ZIP）](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.56/FileBrowserR-v0.2.56-win-x64.zip)**
- [ZIPのSHA-256](https://github.com/mezon-web/FileBrowserR-Releases/releases/download/v0.2.56/FileBrowserR-v0.2.56-win-x64.sha256)
- [更新内容](https://github.com/mezon-web/FileBrowserR-Releases/releases/tag/v0.2.56) · [過去バージョン](https://github.com/mezon-web/FileBrowserR-Releases/releases)
- [詳しい使い方](使い方.md)

ディスク使用量のマップと内訳の選択が連動し、右クリックした行に対して操作できます。音量ミキサーでは、固定アプリが停止しても同じ画面で名前を保持します。

**[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/ja-jp/download/dotnet/10.0)が必要です。** .NET本体は同梱していません。アプリの依存DLLは`FileBrowserR.exe`へ内包し、表示は日本語のみです。

## 起動方法

1. .NET 10 Desktop Runtime x64をインストールします。
2. ZIPを新しいフォルダーへ展開します。
3. `FileBrowserR-v0.2.56-win-x64`内の`FileBrowserR.exe`を起動します。

通常のファイル操作と機能表示は一般ユーザー権限で動作します。管理者のディスクスキャンや温度取得は、機能内で明示的に選んだときだけ専用ワーカーを起動します。ドライバーの自動導入や、Windowsの既定ファイラー・関連付けの変更は行いません。

## 主な機能

- タブ、タブのドラッグ移動、左右2分割、作業状態保存。
- 一覧の現在地へ自動追従するフォルダーツリー、お気に入り、履歴、パンくず、UNCとネットワークドライブ。
- 一覧の絞り込み、正規表現、複数フォルダーの再帰検索。
- コピー・移動・削除・改名、操作キュー、一括リネーム、ZIP作成・展開、7z/RARの閲覧・展開。
- フォルダーの内容／SHA-256比較、書庫内の閲覧専用比較、テキストの左右差分表示。
- アプリ・URLのランチャー、ディスク使用量、メモリマップ、音量ミキサー、システムモニター。
- ライト／ダーク／OS追従、文字サイズ、列とツールバーの調整。

## 画面の使い方

左端のアイコンでツリー・お気に入り・履歴を開閉できます。左右2分割では、操作対象のペインの現在地へツリーが追従します。右端の機能アイコンは再クリックでペインを収納し、もう一度押すと状態を保って開きます。分離ウィンドウのアイコンは前面化します。アイコンは上下へドラッグして並べ替えできます。

左右にフォルダーを開いている場合は、上部の「左右のフォルダーを比較」で直接比較できます。比較一覧は左右2ペイン／統合、ツリー／ファイルのみを切り替えられます。フォルダーや、書庫内比較を有効にした書庫は一覧上で展開できます。表示項目・列は一覧上で、比較方法や書庫内比較などの条件は「比較設定…」で変更します。

比較条件を変えると「再比較待ち」と表示し、「再比較」で更新します。自動では開始しません。比較は読み取り専用です。比較アイコンの再クリックや「ファイル管理に戻る」で比較を終了すると結果を破棄します。

ディスク使用量は「スキャン → 中止 → 管理者」の順です。スキャンを青系の背景・枠で強調します。サンバースト・アイシクル・ツリーマップの色付き領域は濃い背景と白い文字で表示し、中央の説明はテーマに追従します。

ファイル一覧と比較一覧ではEXEごとのアイコンを表示します。メモリマップの下部には選択したアプリの概要が表示され、「内訳」から個別のPIDを選べます。システムモニターの「表示・更新…」では、項目名をクリックして上下ボタンで移動するか、つまみをドラッグして並べ替えられます。

## コマンドラインから比較

```powershell
FileBrowserR.exe --compare "左のパス" "右のパス"
FileBrowserR.exe --compare "左のパス" "右のパス" --differences-only
FileBrowserR.exe --portable
```

左右の対象を指定して比較画面を直接開けます。相対パスはコマンドを実行したフォルダーが基準です。

## 設定と更新

通常の設定はWindowsのユーザー別アプリデータへ保存します。`--portable`ではEXEの隣の`UserData`を使います。更新時はアプリを終了し、新しいZIPを別のフォルダーへ展開してください。設定・履歴を含む`UserData`を他の人へ配布しないでください。

## ファイルの確認

```powershell
Get-FileHash .\FileBrowserR-v0.2.56-win-x64.zip -Algorithm SHA256
Get-Content .\FileBrowserR-v0.2.56-win-x64.sha256
```
